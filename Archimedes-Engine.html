THE EQUATIONS / IMPLEMENTATION 0.1.0

From state to possibility.

An explicit numerical adaptation of the Archimedes kernel. Every simulated transition has a defined operation, a bounded domain, and a trace.

AE–001 / WORLD

A state with a history

Wn = (F, O, A, M, H, P, U, E, Θ, s)n

A scalar field, objects, two agents, their self-models, checkpoint graph, player state, intention, simulated evidence, parameters, and pseudorandom state. One tick is 0.1 simulation seconds.

AE–002 / FIELD

Diffuse, source, decay

F′ = Π[0,1][F + Δt (d∇²hF + q − μF)]

A five-point grid Laplacian with reflecting boundaries. The explicit positivity condition is Δt(4d + μ) ≤ 1. The allowed range gives at most 0.4055.

AE–004 / SELF-MODEL

Observe, then update

m′ = m + (1 − e−αΔt)(y − m)

Position and energy are observed each tick. Field readings are noisy, intermittent, and held during a blackout. This is an exponential observer, with no language model.

AE–006 / COHERENCE

Measure disagreement

C = 1 − ‖x − m‖ / (‖x‖ + ‖m‖ + ε)

D = ‖x − m‖² + 0.02‖ẋ − ṁ‖² − 0.06R

C is bounded from zero to one; D can be negative. High coherence describes agreement inside this model. It does not authenticate a claim.

AE–007 / FEEDBACK

Let coherence affect motion

arec = λΦ (S mpos − p)

2Φ̇ = 0.9Φ − 0.9Φ³ − 1.5Φ‖x − m‖² − 0.02Φ‖ẋ − ṁ‖² + 0.1R

The lagged self-model supplies a restoring acceleration. Set λ to zero to remove this causal pathway. Φ is projected onto [0, 1.5].

AE–009 / RECURSIVE SEARCH

Explore. Score. Retain.

J(a₀…ad−1) = ∑k=0d−1 0.9k U(Wk+1, ak−1)

Expand four intentions, keep the best three branches, and repeat for one to four levels. Only the first chosen intention is applied. This is bounded beam search in a receding horizon, with no global optimality claim.

READING THE LABORATORY

Follow the consequences.

  1. Run the world. ADA and NOETHER act on the current intention.
  2. Inject a field pulse or sensor blackout. Watch the gap between actual state and self-model.
  3. Explore possible futures. Colored paths show the retained best sequence; scores are internal utilities.
  4. Apply the first intention, then observe what actually unfolds.
  5. Return to a checkpoint and try another intervention.

The field and room are a deliberately small computational model. The coherence monitor is inspired by the EFMW Archimedes paper. These results do not establish physical EFMW effects, consciousness, AGI, or an advantage over external benchmarks.

Agents sense their own position and energy continuously and the field intermittently. The player’s branch planner can inspect the full simulated world. All evidence displayed here is generated by this simulator.
